# Security

Report authentication, integrity, matchmaking, or privacy vulnerabilities privately to `spirerace@163.com`.

Do not open a public issue containing Steam session tickets, API keys, access tokens, integrity signing secrets, SSH keys, TLS private keys, database credentials, or production logs with player identifiers.

The integrity system is an application-level deterrent. It rejects unknown files and mods but does not claim to defeat kernel-level tooling or a fully forged client.
